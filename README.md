## ✦ Frames 3.0

Frames 3.0 is a complete visual and interaction refresh.

The app has been redesigned around a quieter editorial aesthetic: large
typography, clean surfaces, subtle motion, rounded custom controls, and
wallpaper-first layouts.

Version 3.0 focuses on making the entire experience feel connected ---
from onboarding to discovery, search, categories, saved wallpapers,
preview, settings, and wallpaper actions.

------------------------------------------------------------------------

### Cinematic UI

-   Editorial typography
-   Custom rounded-square controls
-   Clean spacing and visual hierarchy
-   Dark and Light theme support
-   Subtle transitions and tactile interactions

-   No unnecessary visual noise

## 🚀 Getting Started

### Clone Repository

``` bash
git clone https://github.com/souravkaushik-dev/dotty.git
cd dotty
```

### Install Dependencies

``` bash
flutter pub get
```

### Configure Environment Variables

Create a `.env` file in the project root:

``` env
API_URL=YOUR_API_URL
API_KEY=YOUR_API_KEY
```

Use the environment variables required by your configured wallpaper API.

### Run Application

``` bash
flutter run
```

### Build APK

``` bash
flutter build apk --release
```
