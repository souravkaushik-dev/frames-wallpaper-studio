# 🌿 Foliage Wallpaper Studio

**Foliage** is another visual evolution of the **Frames Wallpaper Studio** — designed around **Material 3 Expressive** and inspired by the beauty, texture, and character of floral and botanical wallpapers.

Foliage brings the same powerful wallpaper experience into a fresh, nature-focused interface, with a design language built to feel expressive, modern, and alive.

## ✨ Features

* 🌸 **Floral & Botanical Focus** — A wallpaper experience centered around nature, foliage, flowers, and organic visuals.
* 🎨 **Material 3 Expressive** — A completely refreshed interface inspired by Google's expressive Material design direction.
* 📥 **Download Wallpapers** — Save wallpapers directly to your device.
* ❤️ **Save Favorites** — Keep your favorite wallpapers in one place.
* 🏠 **Apply to Home Screen** — Set wallpapers directly to your home screen.
* 🔒 **Apply to Lock Screen** — Set wallpapers directly to your lock screen.
* 🏠🔒 **Apply to Both** — Set the same wallpaper on both your home and lock screens.
* 🖼️ **Wallpaper Preview** — Preview wallpapers before downloading or applying them.
* 📱 **Modern Wallpaper Experience** — Built to make discovering and using wallpapers simple and enjoyable.

## 🌱 A New Version of Frames

Foliage is built as another version of **Frames Wallpaper Studio**, carrying forward the core wallpaper experience while introducing a new visual identity.

For now, **Foliage uses the same wallpaper collection featured in Frames Wallpaper Studio**. As development continues, the two apps will gradually receive **different wallpaper collections and identities**, making Foliage its own dedicated floral and botanical wallpaper destination.
